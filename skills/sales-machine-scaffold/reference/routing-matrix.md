# Routing matrix

Invoke as `/sales-machine-scaffold <cmd>`. If commands are not parsed, read `<cmd>` from the message.

| cmd             | Use when the user wants to...                                                | Section                                                                 |
| --------------- | ---------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| `setup`         | start a sales machine for a product, fill or change the config               | [workflows/setup/SKILL.md](../workflows/setup/SKILL.md)                 |
| `explore`       | map what the product does and what is live, from code and docs               | [workflows/explore/SKILL.md](../workflows/explore/SKILL.md)             |
| `position`      | define who we talk to, the promise, the personas and the say/never-say rules | [workflows/position/SKILL.md](../workflows/position/SKILL.md)           |
| `machine`       | design or review the 6 stages, lanes, buying signals, engine and metrics     | [workflows/machine/SKILL.md](../workflows/machine/SKILL.md)             |
| `loops`         | design or measure growth loops (integrations, invites, content)              | [workflows/loops/SKILL.md](../workflows/loops/SKILL.md)                 |
| `article-ideas` | draft a batch of ready articles                                              | [workflows/article-ideas/SKILL.md](../workflows/article-ideas/SKILL.md) |
| `landing`       | write landing page specs: home, persona and integration sub-pages            | [workflows/landing/SKILL.md](../workflows/landing/SKILL.md)             |
| `manual`        | write the brand + sales manual or the sales training ebook                   | [workflows/manual/SKILL.md](../workflows/manual/SKILL.md)               |
| `value-audit`   | check copy, an article or a page against the Elements of Value and the rules | [workflows/value-audit/SKILL.md](../workflows/value-audit/SKILL.md)     |
| `system-spec`   | write the HCL spec of the finished machine as an agent-operated system       | [workflows/system-spec/SKILL.md](../workflows/system-spec/SKILL.md)     |
| `report`        | build the final self-contained HTML audit report                             | [workflows/report/SKILL.md](../workflows/report/SKILL.md)               |
